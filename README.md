# Folio

Planner and notebook constructor. Live at **https://nastyaoleyna.github.io/folio/**

- Sign in with email and password; planners sync through Supabase (project `folio`).
- `setup.sql` is the database setup that is already applied to the project.
- To update the app, replace `index.html` (and any changed files) and commit. Don't change `config.js`.
